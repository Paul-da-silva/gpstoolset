# GPS Toolset — Keyword Planner data (gpstoolset.com)

All keyword research runs for this project, in one place. Data is from **Google Keyword Planner**, run by Paul and exported as CSV/TSV.

- **Volumes are ranges**, not exact numbers (the account has no ad spend, so Google only shows buckets).
- **Competition = advertiser competition** for paid ads, **not** SEO difficulty.
- **Banned wording:** rows containing "Telemetry Extractor" are kept as raw research only. Paul's rule: never use those words on the site.
- **Target page / status** comes only from the SEO briefs where clearly stated; blank means no target decided yet.
